Pipeline

The medallion architecture, without the plumbing.

Every upload is written to a Bronze Delta table as-is. Spark cleans it and enforces a schema in Silver, then Gold builds a query-ready table. It all runs in the background, so the dashboard stays responsive.

  • “N/A” text becomes missing, TOTAL rows are dropped, duplicate emails removed
  • Excel header rows are detected, one table per useful sheet
  • If a stage fails, retry just that dataset

Semantic search

Find rows by what they mean, not what they say.

Text is embedded with all-MiniLM-L6-v2 and images with CLIP, then indexed in FAISS, one index per dataset. Search a single table, or every dataset with matching columns at once.

Reports

Ask in English. Get a checked query and a written answer.

The planner turns your question into a validated query, the result is analysed in code, and the LLM writes the summary. Filters are checked against real column names before anything runs.

For developers

Everything the dashboard does is an API call.

A FastAPI backend with JWT auth. Upload in bulk, watch the pipeline, query Gold tables and run semantic search from your own scripts.

POST/auth/login
POST/upload/bulk
GET/pipeline/status
POST/sql/query
POST/search/query
POST/reports/generate
Open the interactive API docs → 
# 1. log in and keep the token
TOKEN=$(curl -s -X POST localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"you","password":"your-password"}' | jq -r .access_token)

# 2. upload a file (Silver, Gold and the index run in the background)
curl -X POST localhost:8000/upload/bulk \
  -H "Authorization: Bearer $TOKEN" \
  -F "files=@retail_orders.csv"

# 3. average price per category from the Gold table
curl -X POST localhost:8000/sql/query \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"table_name":"retail_orders","group_by":["category"],
       "agg_column":"price","agg_func":"mean"}'
import requests

API = "http://localhost:8000"
token = requests.post(f"{API}/auth/login",
    json={"username": "you", "password": "your-password"}).json()["access_token"]
auth = {"Authorization": f"Bearer {token}"}

with open("retail_orders.csv", "rb") as f:
    requests.post(f"{API}/upload/bulk", headers=auth, files=[("files", f)])

hits = requests.post(f"{API}/search/query", headers=auth, json={
    "table_name": "retail_orders", "query": "cheap winter jackets", "top_k": 5,
}).json()["rows"]
const API = "http://localhost:8000";

const { access_token } = await fetch(`${API}/auth/login`, {
  method: "POST", headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ username: "you", password: "your-password" }),
}).then(r => r.json());

const report = await fetch(`${API}/reports/generate`, {
  method: "POST",
  headers: { "Content-Type": "application/json", Authorization: `Bearer ${access_token}` },
  body: JSON.stringify({ table_name: "retail_orders", question: "Which category sells the most?" }),
}).then(r => r.json());

console.log(report.summary);
Run locally

Up and running in three steps.

1

Install

You need Python 3 and Java (for Spark). Then, inside lakehouse_backend:

python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
2

Configure

Copy the example env file. A Groq key is optional; it lets the LLM write reports.

copy .env.example .env
# GROQ_API_KEY=...
# JWT_SECRET_KEY=...
3

Start

Run the API, then open index.html and create an account.

uvicorn main:app --reload
# API on localhost:8000

Questions

What happens to a file that doesn’t parse?

It still lands in Bronze. The stage that failed is marked on the Pipeline page with its error, and you can retry that dataset from there.

Which LLM writes the reports?

A Groq-hosted model, set with GROQ_MODEL_NAME in .env. Without a GROQ_API_KEY, reports still work using a rule-based planner and a computed summary.

Can I search across all my datasets at once?

Yes, when two or more datasets have exactly the same columns, for example several mailboxes from the same export. An “All datasets (combined)” option then appears in SQL Explorer, Semantic Search and Reports.

Can I search images?

Yes. Images uploaded together become one collection, embedded with CLIP, so you can search them with a description like “a stock price chart”. Results come back as thumbnails.

Is my data sent anywhere?

Storage, Spark and the search indexes all run on your machine. The only outside call is to Groq, when you generate a report with an API key set.
